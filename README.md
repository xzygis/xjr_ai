# 小游戏中心 (Mini Games Center)

本项目包含一系列使用 HTML5、CSS3 和 Vanilla JavaScript 制作的轻量级小游戏。

## 游戏列表

### 1. 商店模拟器 (Shop Simulator)
一个模拟经营类小游戏。
- **玩法**：玩家扮演商店老板，经营一家拥有100种各类生活用品的杂货店。游戏具有完整的经济系统，顾客会不断进入商店挑选商品并在收银台排队结账。
- **特色**：
  - 100种不同的真实商品（食品、数码、文具、家具等）。
  - 随机生成的中文名字顾客，真实的浏览和排队路线。
  - **升级系统**：可以花费资金购买扩展货架、雇佣自动化收银员，或进行营销来增加客流量。
  - **状态保存**：资金和升级进度会自动保存在浏览器的 LocalStorage 中。
- **技术栈**：原生 HTML/CSS/JS、LocalStorage、CSS 动画和绝对定位。
- **访问路径**：`games/shop-simulator/index.html`

### 2. 滚铁球 (Rolling Ball)
一个伪3D透视的铁球轨道滚动游戏。
- **玩法**：操控铁球在双轨铁道上滚动前进，穿越隧道、躲避障碍物、利用加速带冲上坡道。通关后铁球与新球融合变大，轨道也随之变宽，进入更高难度的关卡。
- **特色**：
  - 伪3D透视渲染引擎，金属质感铁球和铁轨。
  - 5个递进式关卡：直线教学 → 隧道信号灯 → 极速坡道 → 旋转轨道 → 终极综合挑战。
  - **红绿灯信号系统**：红灯时隧道内出现障碍物，绿灯安全通过。
  - **加速带**：上坡路段的黄色箭头加速区，助力冲坡。
  - **铁球融合**：每通一关球体变大、轨道变宽，视觉与操控随之变化。
  - **旋转轨道**：高难度关卡中轨道会旋转偏移，考验操控能力。
- **技术栈**：HTML5 Canvas 2D、原生 JavaScript、伪3D投影算法。
- **访问路径**：`games/rolling-ball/index.html`

### 3. 数学跑酷大冒险 (Math Parkour)
一个面向二年级小朋友的数学答题+横版跑酷闯关游戏。
- **玩法**：每关开始前需答对数学题才能进入跑酷，跑酷中碰到障碍可答题复活。全部8关通过后展示成绩统计。
- **数学题系统**：
  - 7种题型：两位数加减法、九九乘法表、比较大小、填空题、应用题。
  - 每题15秒倒计时，随关卡递增难度。
- **8大主题关卡**：
  1. 🌿 草地跑酷 — 跳过石头和栅栏
  2. 🌲 森林冒险 — 躲避移动树桩
  3. 🏙️ 城市奔跑 — 小心汽车和路障
  4. ☁️ 天空飞行 — 获得翅膀上下躲避
  5. 🐠 水下探险 — 游泳避开水母鲨鱼
  6. ❄️ 冰雪世界 — 躲避掉落冰锥
  7. 🌋 火山地带 — 躲开岩浆球和裂缝
  8. 🚀 太空漫步 — 低重力陨石来袭
- **操控**：空格/上箭头跳跃，下箭头滑铲/下潜，支持触屏。
- **技术栈**：HTML5 Canvas、Web Audio API 合成音效、纯原生 JavaScript。
- **访问路径**：`games/math-parkour/index.html`

### 4. 走路大冒险 (Walk Runner)
一个俯视角走路闯关游戏。
- **玩法**：从山顶出发，穿越下坡、独木桥、山川险路、废墟和坑洞路障区，一路走到终点赢取奖杯。路上有大量行人NPC，撞到他们会将其撞倒，但撞到墙壁或路障自己会倒地。到达终点获得奖杯，可抽取宠物蛋，每个宠物蛋增加100%移动速度。
- **特色**：
  - **8大地形区域**：山顶起点 → 下坡路段 → 平地过渡 → 独木桥 → 山川险路 → 废墟区 → 坑洞路障区 → 终点。
  - **60个NPC行人**：自主移动，被撞后倒地并显示X眼。
  - **坑洞路障系统**：坑洞用红白路障围起来，碰到无法通过。
  - **墙壁碰撞**：撞到墙壁/路障会导致自己倒地，需等待恢复。
  - **宠物蛋系统**：到终点获得奖杯 → 空格抽取宠物蛋 → 速度+100%，宠物围绕角色旋转。
  - **无限关卡**：通关后地图随机重新生成，难度递增。
- **操控**：U左 O右 K前 J后，空格抽宠物蛋。
- **技术栈**：HTML5 Canvas、原生 JavaScript、Tile-based 地图系统。
- **访问路径**：`games/walk-runner/index.html`

### 5. 数学跑酷 (Math Runner)
一个跑酷+数学答题结合的小游戏。
- **玩法**：角色自动奔跑，玩家控制跳跃和加速躲避障碍物。撞到障碍物后弹出数学题，答对可继续游戏，答错累计3次则游戏结束需重新开始。
- **特色**：
  - 加减乘三种运算，难度随跑动距离递增。
  - 三种不同形态的障碍物（尖刺、方块、高墙）。
  - 粒子特效和夜间霓虹风格视觉。
  - 按住 D/→ 可加速奔跑。
- **操控**：空格/↑/W 跳跃，→/D 加速。
- **技术栈**：HTML5 Canvas、原生 JavaScript、CSS 动画弹窗。
- **访问路径**：`games/math-runner/index.html`

### 6. 枪战基地保卫战 (Gun Battle)
一个粒子对抗基地防守游戏。
- **玩法**：屏幕中央有一个蓝色方框基地，红色敌人从四面八方涌来。按A召唤小兵（蓝色小粒子）在基地内防守射击，按B召唤大兵（蓝色大粒子）出基地主动出击歼敌。蓝红粒子碰撞即爆炸消灭。
- **特色**：
  - 每秒海量红色敌人从屏幕边缘涌入。
  - 小兵在基地内弹跳移动，自动射击靠近的敌人。
  - 大兵主动追踪最近的敌人，拥有3点HP，可消灭多个敌人。
  - 霓虹辉光风格，暗色背景+粒子爆炸特效。
  - 实时显示击杀数、兵力数、敌人数。
- **操控**：A = 召唤小兵，B = 召唤大兵。
- **技术栈**：HTML5 Canvas、原生 JavaScript、粒子系统。
- **访问路径**：`games/gun-battle/index.html`

## 开发与运行

1. 克隆本项目。
2. 在项目根目录启动一个本地 HTTP 服务器，例如使用 Python：
   ```bash
   python3 -m http.server 8000
   ```
3. 在浏览器中打开 `http://localhost:8000` 即可看到游戏中心入口。
