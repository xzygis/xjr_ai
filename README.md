# xjr-ai 小游戏中心

这是一个包含多个 HTML5 小游戏的集合项目，所有游戏都可以直接在浏览器中运行。项目采用响应式设计，完美适配 PC、平板和手机端。

## 在线体验
可通过 GitHub Pages 零成本部署并访问（具体链接根据你的部署情况生成）。

## 项目结构

```text
xjr-ai/
├─ index.html                 # 游戏大厅（首页）
├─ games/                     # 游戏目录
│  ├─ parkour-game/           # 无尽跑酷游戏
│  ├─ battle-royale-shooter/  # 枪战吃鸡战场
│  ├─ 3d-shooter/             # 3D 射击游戏
│  ├─ racing/                 # 赛车狂飙
│  ├─ snake/                  # 无敌贪吃蛇
│  ├─ bomb-earth/             # 炸穿地球逃离空岛，变身海洋动物变身晋级
│  └─ airplane-flight/        # 模拟飞行：超音速迫降
├─ .trae/
│  └─ rules/
│     └─ project_rules.md     # 项目开发规范
└─ skills-lock.json
```

## 游戏列表

1. **[枪战吃鸡战场](./games/battle-royale-shooter/)**
   - **简介**：俯视视角射击生存游戏，深绿色无尽跑酷场背景。
   - **特色**：
     - 开局自带 20 名特种队员环绕基地进行防守扫射。
     - 敌人如潮水般涌来（每秒10个），节奏极快。
     - 包含多种强力武器（手枪、冲锋枪、狙击枪、火箭、突击步枪）。
     - 支持呼叫大杀器（核弹、氢弹）全屏清怪。
     - 购买“自由远景车（奔驰/宝马等）”或“火箭”可冲出基地碾压敌人，但停车会被警察车抓捕。
     - 支持移动端触摸屏幕进行射击。

2. **[无尽跑酷](./games/parkour-game/)**
   - **简介**：经典的横版 2D 跑酷游戏。
   - **特色**：
     - 简单的跳跃机制，长按跳跃键可实现短暂滑翔飞行。
     - 动态生成的障碍物。
     - 支持移动端触摸屏幕进行跳跃。

3. **[赛车狂飙](./games/racing/)**
   - **简介**：极速赛车体验。
   - **特色**：驾驶你的赛车在赛道上驰骋。

4. **[3D 射击生存](./games/3d-shooter/)**
   - **简介**：基于 Three.js 的第一人称 3D 射击游戏。
   - **特色**：沉浸式 3D 环境，对抗 AI 敌人，包含跳跃、冲刺和射击机制，死亡后可在家中复活。

5. **[无敌贪吃蛇](./games/snake/)**
   - **简介**：大乱斗模式的贪吃蛇游戏。
   - **特色**：超大地图，碰到边界反弹，蛇头碰到别的蛇身体才会死，吃掉比自己短的蛇成为霸主！适配移动端触屏操作。

6. **[炸穿地球逃离空岛，变身海洋动物变身晋级](./games/bomb-earth/)**
   - **简介**：炸穿地球掉入海洋，从贝壳进化为人类开始荒岛生存！
   - **特色**：
     - **炸穿地球阶段**：包含多种炸弹（圆形炸弹、炮竹、TNT、C4、原子弹、氢弹、中子弹），目标是炸穿 1 亿万千米深的地球。
     - **海洋进化阶段**：掉入海里后，小鱼吃贝壳 -> 大鱼吃海龟 -> 海龟吃水母 -> 鲨鱼吃鲸鱼 -> 鲸鱼变海豚 -> 虎鲸 -> 人类。
     - **荒岛生存阶段**：化身人类住进茅草屋，每天必须钓鱼，饿了吃汉堡，渴了喝水。

7. **[模拟飞行：超音速迫降](./games/airplane-flight/)**
   - **简介**：飞机驾驶与紧急求生模拟游戏。
   - **特色**：
     - **登机起飞**：在飞机场按 R 键打开舱门让乘客登机，按空格键启动引擎起飞。
     - **紧急弹射**：如果发生坠机，可以按下 J 键脱落外壳，化身超音速战机逃生。
     - **赏罚系统**：安全降落奖励 10 元，坠机完全损毁罚款 1 元。

## 本地运行

在项目根目录执行以下命令启动本地服务器：

```bash
python3 -m http.server 8000
```

然后在浏览器打开游戏大厅：

```text
http://localhost:8000/
```

## 开发与维护规范

请参考 `.trae/rules/project_rules.md` 文件了解详细的目录规范和开发流程。每次更新或新增游戏后，请务必同步更新本 README 和根目录的 `index.html`。

核心约束：

1. 每个新游戏必须放在 `games/<game_name>/` 目录
2. 每个游戏入口文件统一为 `games/<game_name>/index.html`
3. 每次创建新游戏后，**必须**同步更新项目根目录的 `index.html`，将新游戏添加到“小游戏中心”的列表中
4. 正式业务代码不放在 `.trae/`（规则文件目录除外）
